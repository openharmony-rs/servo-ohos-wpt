Servo OpenHarmony WPT pass rates

Web Platform Tests results of the ohos-main commits of servo-ohos, one line per configuration. The upstream base line shows the results of the servo/servo commit that each tested commit is based on, and dotted vertical lines mark rebases onto a newer upstream. The score counts each test as the fraction of its subtests that pass, like Servo's own dashboard. Skipped tests are not counted. Pick a directory in the table to see its history and its tests.
